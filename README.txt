# Charm and Corner Creations — Free Store Website

## Add your cover photo
Put your image in this folder and name it:
cover.jpg

## Add product photos
Put these files in the folder:
product-1.jpg
product-2.jpg
product-3.jpg

You can edit product names, prices and descriptions near the top of the JavaScript section in `index.html`.

## Add payment numbers
Open `index.html` and find:
settings = {
  bkashNumber: "YOUR_BKASH_NUMBER",
  nagadNumber: "YOUR_NAGAD_NUMBER",
  whatsapp: "YOUR_WHATSAPP_NUMBER"
};

Replace the placeholders with your business numbers.

IMPORTANT:
This version collects orders and payment instructions. It does not perform automatic bKash/Nagad payment verification. For automatic payment processing, you need an approved merchant/API integration and credentials from the payment provider.

## Free hosting
You can upload these files to a static web host such as GitHub Pages or another free static hosting service. The site itself has no monthly software fee.
